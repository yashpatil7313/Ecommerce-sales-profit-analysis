# E-Commerce & Retail Sales Performance Analysis

An end-to-end exploratory data analysis (EDA) project evaluating sales, profitability, customer segments, and temporal trends from the Superstore retail dataset.

---

## 📌 Project Overview
This project uncovers retail performance drivers across different dimensions—including seasonal patterns, category margins, and customer behavior—using Python and interactive Plotly visualizations.

---

## 🔍 Key Highlights & Insights
- **Temporal Analysis:** Extracted month, year, and day-of-week trends to track monthly sales peaks and profit cycles.
- **Category & Sub-Category Performance:** Evaluated revenue vs. margin contributions across Furniture, Office Supplies, and Technology.
- **Segment Contribution:** Compared sales distribution and profitability between Consumer, Corporate, and Home Office groups.
- **Interactive Dashboards:** Visualized line charts, donuts, and grouped bar charts using Plotly.

---

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Plotly Express, Plotly Graph Objects
- **Environment:** Jupyter Notebook
